# Multi-Dataset Support for CLIP Adaptation Benchmark

Aggiungere supporto per 8 dataset aggiuntivi oltre a EuroSAT, mantenendo la stessa interfaccia `(image, label, class_text)` e la compatibilità con tutti i metodi esistenti (ZeroShot, LinearProbe, OT, e i futuri CoOp/Adapter).

> [!IMPORTANT]
> I dataset "Manual download" richiedono che l'utente scarichi i dati e li posizioni in `./data/<nome_dataset>/` con struttura ImageFolder (`classe/immagine.jpg`). Il codice rileverà automaticamente le classi dai nomi delle cartelle.

> [!WARNING]
> **StanfordCars**: il download ufficiale è spesso non disponibile. Se fallisce, verrà trattato come dataset ImageFolder (l'utente scarica manualmente).

## Proposed Changes

### Dataset Module

#### [MODIFY] [dataset.py](file:///c:/Code/APAI/APAI_exam/dataset.py)

Riscrittura completa per supporto multi-dataset:

1. **Registry `DATASET_CONFIGS`**: dizionario che mappa `dataset_name → DatasetConfig` con:
   - `class_names`: lista delle classi (per torchvision) o `None` (per ImageFolder, auto-detect)
   - `prompt_template`: template specifico per dominio
   - `loader_type`: `"torchvision"` o `"imagefolder"`
   - `torchvision_class`: la classe torchvision (es. `datasets.DTD`)
   - `split_ratios`: come dividere train/test se il dataset non ha split builtin

2. **Classe `CLIPDataset`**: wrapper generico che sostituisce `EuroSATDataset`, accetta qualsiasi dataset torchvision o ImageFolder e ritorna `(image, label, class_text)`.

3. **Funzione `get_dataloaders(dataset_name="eurosat", ...)`**: factory aggiornata con parametro `dataset_name`. Ritorna `(train_loader, test_loader, dataset_info)` dove `dataset_info` contiene `class_names` e `prompt_template`.

4. **Backward compatibility**: `EUROSAT_CLASS_NAMES` e `PROMPT_TEMPLATE` restano esportati come alias.

5. **Funzione `list_available_datasets()`**: ritorna i nomi disponibili.
